# Hero images

Full-size hero artwork downloaded from [Bullet Echo Wiki](https://bullet-echo.fandom.com/wiki/Category:Heroes), including individual hero pages for Alter, Graviel, Scratch, and Vi.

Source image URLs are recorded in `src/heroes.js`. Run `node scripts/download-heroes.js` to refresh the local WebP files.
